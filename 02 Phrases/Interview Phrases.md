# Interview Phrases - Technical Interviews

## Introducing yourself
- I'm a frontend developer with 3 years experience in React. 
  → Saya pengembang frontend dengan 3 tahun pengalaman di React.
- I specialize in building scalable backend APIs. 
  → Saya spesialis membangun API backend yang skalabel.

## Explaining a project
- I built an e-commerce checkout using Next.js and Stripe. 
  → Saya membangun checkout e-commerce memakai Next.js dan Stripe.
- The main challenge was reducing latency. 
  → Tantangan utamanya mengurangi latensi.
- We improved performance by 40% with caching. 
  → Kami meningkatkan performa 40% dengan caching.

## System design talk
- Let's start with requirements. 
  → Mari mulai dari kebutuhan.
- I'll assume 1M daily active users. 
  → Saya asumsikan 1 juta pengguna aktif harian.
- Trade-off: consistency vs availability. 
  → Pertimbangannya: konsistensi vs ketersediaan.

## When stuck
- Could I think aloud for a moment? 
  → Bolehkah saya berpikir keras sebentar?
- I'm not sure, but I'd approach it by... 
  → Saya tidak yakin, tapi saya akan dekati dengan...
- Could you give me a hint? 
  → Bisa beri petunjuk?

## Closing
- What does success look like in this role? 
  → Seperti apa kesuksesan di peran ini?
- What's the tech stack? 
  → Apa tech stack-nya?
