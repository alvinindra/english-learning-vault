# Code Review Phrases

| Intent | English | Indonesian |
|---|---|---|
| Suggest | Could we extract this into a function? | Bisakah kita ekstrak ini jadi fungsi? |
| Clarify | What happens if the API returns null? | Apa yang terjadi jika API mengembalikan null? |
| Praise | Nice refactor, much cleaner! | Refaktor bagus, jauh lebih bersih! |
| Nitpick | Nit: typo in variable name. | Nit: ada typo di nama variabel. |
| Approve | Approved, please merge after tests pass. | Disetujui, silakan gabung setelah tes lulus. |
| Request changes | Please add error handling here. | Tolong tambahkan penanganan error di sini. |
