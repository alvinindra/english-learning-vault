# Daily Standup Phrases

Use these templates every morning.

## English → Indonesian
1. **Yesterday I worked on...** → Kemarin saya mengerjakan...
   - Yesterday I worked on fixing the login bug.
1. **Today I will...** → Hari ini saya akan...
   - Today I will implement the API endpoint.
1. **I am blocked by...** → Saya terhambat oleh...
   - I am blocked by waiting for design assets.
1. **I need help with...** → Saya butuh bantuan untuk...
2. **It's ready for review.** → Sudah siap untuk direview.

Practice: record yourself saying each 3x.
