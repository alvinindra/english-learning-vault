# System Design Discussion Phrases

| Intent        | English                                          | Indonesian                                                |
| ------------- | ------------------------------------------------ | --------------------------------------------------------- |
| Clarify scope | What are the functional requirements?            | Apa kebutuhan fungsionalnya?                              |
| Estimate      | Let's estimate QPS and storage.                  | Mari perkirakan QPS dan penyimpanan.                      |
| Propose       | I'd use a load balancer in front of app servers. | Saya akan pakai load balancer di depan server aplikasi.   |
| Trade-off     | This improves availability but adds complexity.  | Ini meningkatkan ketersediaan tapi menambah kompleksitas. |
| Bottleneck    | The database will be the bottleneck.             | Basis data akan jadi hambatan.                            |
| Scale         | We can shard by user ID.                         | Kita bisa shard berdasarkan user ID.                      |
