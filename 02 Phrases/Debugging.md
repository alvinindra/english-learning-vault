# Debugging Phrases

- **It works on my machine.** → Di komputer saya jalan.
- **Can you reproduce it?** → Bisa direproduksi?
- **Check the console logs.** → Cek log konsol.
- **It's a race condition.** → Ini kondisi balapan.
- **Let's add some logging.** → Mari tambahkan logging.
- **The bug is intermittent.** → Bug-nya kadang-kadang muncul.
