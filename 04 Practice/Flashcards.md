# Flashcards - Spaced Repetition

Format for Obsidian SR plugin: Question on left, answer after ::

Q:: What is "deploy" in Indonesian?
A:: Rilis / deploy 
Example: Deploy to production

Q:: Translate: "Please approve my PR"
A:: Tolong setujui PR saya

Q:: What does "refactor" mean?
A:: Menulis ulang kode tanpa mengubah perilaku → Refactor is to rewrite code for clarity

Q:: Indonesian for "endpoint"?
A:: Titik akhir (but we usually say endpoint)

Q:: Say in English: "Saya terhambat menunggu API"
A:: I'm blocked waiting for the API

Q:: What is "bug" in Indonesian dev slang?
A:: Bug / masalah.  (we usually keep say "bug")

Q:: Translate: "Reduce bundle size"
A:: Kurangi ukuran bundel

Q:: Imperative: "Jalankan server"
A:: Run the server

Q:: What is "middleware"?
A:: Perantara → A code that runs between request and response

Q:: Translate: "LGTM, ship it!"
A:: Terlihat bagus, lanjutkan!
